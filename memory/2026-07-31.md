# 2026-07-31 — Audit and Measurement Findings

## Input ownership

- Joystick deflection drives the MSX arrow matrix with hysteresis: engage at **±0.5** and
  release at **±0.35**; button A drives Space.
- `driveMsxKey` counts ownership by source so joystick and physical keyboard can hold the
  same key. Blur, power-off, and disposal release every source.
- Pointer probes must hide HUD chrome before raycasting the scene; the panel otherwise
  sits in front of the canvas and produces a false negative.

## Specification audit

- Of 220 requirements, 192 already matched the implementation and 24 gaps were confirmed.
  Fourteen were stale spec values left behind after photographs had correctly changed the
  render. The spec now carries the source image beside each corrected shell/fascia height,
  fillet, button cluster, indicator position, vent count, and color.
- The console-top/keyboard-shell RGB ratio is **0.85/0.74/0.69** in the render versus
  **0.36/0.28/0.25** in the photograph. The albedo ratio is already about **0.44**;
  reducing albedo to one-quarter only moved the first ratio from 0.85 to 0.56. This is a
  lighting-distribution problem: the top receives about twice the keyboard's illumination.
- AgX exposure 0.72 now measures QWERTY keys at **rgb(172,169,162)**, not the documented
  **rgb(184,181,175)**. Exposure 1.0 produces the documented result. Re-run both
  `tools/tune-case.mjs` and `tools/tune-exposure.mjs` before changing either anchor.

## Performance findings

- Four texture workers reduced isolated generation from **750 ms to 227 ms (3.4×)** with
  identical bytes but delayed full-page `__msxReady` by **5–7%** in interleaved A/B
  rounds. Cooperative generation was already overlapped and off the critical path; the
  worker implementation was removed.
- Disabling shader error checks moved roughly **500 ms** from `onFirstUse` to the first
  draw and hid diagnostics without improving readiness. The change was rejected.
- Idle 1080p draw calls decompose as **258 scene + 136 NormalPass + 19 SSAO/bloom + 12
  DoF + 3 SMAA = 429**, or 523 when the shadow atlas refreshes. The target is below 150;
  NormalPass is the largest isolated lever.
- Cold page timing must remain layered: local TTFB **1.1 ms** versus edge **132 ms**;
  document **23 ms** local versus **338 ms** edge; `__msxReady` about **1.7 s**. The edge
  TTFB includes roughly 35 ms TCP plus 40 ms TLS and cannot be attributed to application
  code.
