# 2026-07-30 — Authorial Z80 Game and Local ROMs

- Commercial game ROMs remain out of scope because their copyright is active. The legal
  demonstration is an authorial game executed by WebMSX plus a browser-only path for a
  user's own ROM.
- `SuperCosmicoRom.ts` builds a roughly **450-byte** Z80 space-snake game with a two-pass
  mini-assembler. State lives at `0xE000+`; a 128-position circular queue and score cap
  of 99 limit the tail to 100 cells. Every BIOS call is treated as clobbering
  AF/BC/DE/HL, and `KILBUF` precedes every `CHGET`.
- The routed ROM provider gives the user ROM in `preto-generico` precedence over external
  and built-in authorial providers. Validation allows at most **2 MB** and an `AB`
  signature at offset 0, `0x4000`, or `0x8000`; bytes remain in memory and filenames are
  inserted into the HUD with `textContent`.
- Game probes must hold a key for at least **250 ms**; a 90 ms synthetic tap delivered
  only about 50 ms after contact timing and C-BIOS missed it. Pixel comparisons must use
  distance from the frame's modal color, and horizontal movement must compare columns,
  not row sums. Reinsertion is a valid recovery from a boot/insertion race.
