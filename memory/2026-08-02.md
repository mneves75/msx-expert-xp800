# 2026-08-02

## v0.1.0 — first public release

- History squashed to a single initial commit on `main`; beta tags removed. The GitHub
  repository was recreated (not force-pushed) so that no orphaned object from the private
  era remains fetchable by SHA.
- Version policy reset: the private beta line (`1.0.0-beta.*`) ended at beta.12 and the
  public line starts at `0.1.0`. `package.json` gained `license`, `repository`,
  `homepage`, `bugs`, and `engines`.
- Deployment generalized: `wrangler.jsonc` carries no account values, the production
  probes require a URL (`argv[2]` or `MSX_PROD_URL`), and the README documents deploying
  `dist/` to any static host with the `public/_headers` policies replicated.
- Pre-release verification: ast-grep + typecheck + build green; interactions 13/13,
  keymap 93/93, textures 11/11, hero capture inspected; `probe-game` full pass (one
  timing-flaky step on first run passed on rerun); `pnpm audit` clean; gitleaks clean
  (two false positives on the texture `cacheKey` literal); independent read-only review
  before the push.
