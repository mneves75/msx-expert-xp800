# 2026-09-05 — whole-codebase cleanup

Audited the source, tooling, dependencies and agent guidance against the existing
procedural-rendering and local-ROM contracts. The working plan records the alternatives
considered and their tradeoffs in `agent_planning/audit-2026-09-05.md`.

Removed the HUD's method discovery, unknown-state coercion, retry timers, custom-event
fallback and optimistic slot snapshots. It now receives a typed interaction handle and
one subscription. The original HUD could display a cartridge in slot B after the
interaction layer correctly refused to move the same cartridge out of slot A.

Deleted unused raw-screen CRT processing options, deprecated shader controls, generic
texture generators with no product callers, unreachable cartridge art, utility APIs and
obsolete incident probes. The existing module ownership and abort paths remain intact.

Cartridge rest detection compared position with a command that the physical detent never
reaches. Force/velocity/wobble checks allow rest without changing the trajectory:
9,360 comparison frames at 30/60/144 Hz matched exactly. The focused regression changed
from 18/24 on the baseline to 24/24 after the fix.

Owned InstancedMesh buffers now have explicit disposal; the keyboard no longer claims
ownership of shared cached atlas textures. A real WebGL probe confirmed all 36 uploaded
instance attributes were live before module unregister and deleted afterward.

Disabled WebMSX query configuration overrides and patched nanoid to 3.3.18. The dependency
audit reported no known vulnerabilities. Capture and header guards now reject missing
subjects and broadened policies; their positive and negative controls pass.

Consolidated the project contract into AGENTS.md, imported by CLAUDE.md. A managed local
QA command owns its server, and offline fallback checks are distinct from real-CDN
integration. The first real runner attempt exposed Vite's treatment of port zero as the
default port; a passing build alone did not validate checkout isolation.

Removed the invisible console contact-shadow quad after an A/B showed it contributed no
pixels but enlarged the desk footprint. Desk now respects each instance transform and
hidden ancestors. No calibrated colors or lighting values changed.

Real mobile keyboard testing exposed two interacting defects: opening visibility
transition delayed initial focus, and emulator input captured native button keystrokes.
Opening now focuses immediately, Tab stays inside the modal, and browser controls own
new key strokes while existing MSX key ownership still releases correctly. The focused
suite passes 43/43; the same online checks and actual WebMSX game probe also pass.

ROM-boundary verification used positive instrumentation controls: oversized files caused
zero reads, invalid signatures were refused, filenames stayed text, and accepted local
bytes caused no network requests or persistent writes. Independent Standards and Spec
reviews found no remaining actionable item after their focused recheck.

The final managed offline command passes end to end, including 43/43 interaction checks.
All 15 camera images were inspected. The front pose had a lit CRT covering 2.99% of the
frame, exposing a false failure under the generic 4% coverage threshold; its measured
2% threshold now passes while the dark-screen control still fails. Existing lighting
calibration gaps remain open. Profile counters improved, but noisy timing samples do
not support a general frame-rate claim; see the curated measurements in MEMORY.md.

P3 autoreview found that the new CSP validator treated directive names as case-sensitive.
A real browser control showed a leading uppercase permissive directive executed inline
code while the validator accepted it. ASCII case normalization now rejects that policy;
mixed-case positive and negative regression controls pass. The parser follows the
[CSP parsing algorithm](https://www.w3.org/TR/CSP3/#parse-serialized-policy).

The post-fix autoreview identified Unicode whitespace as a second parser mismatch.
Chromium confirmed the malformed policy dropped both script restrictions. The validator
now rejects non-ASCII tokens and uses exactly CSP's ASCII whitespace; both browser
controls reject the broadened policy while accepting the current headers. Focused
regressions also reject vertical-tab prefixes. No third whole-diff review was run.
An independent final verifier accepted the corrected parser after the guard suite and
34 additional boundary assertions, with no remaining finding in that scope.

The first Linux CI run passed build, guards, mapping, textures and physics but only 27/43
interaction checks. Fixed wall waits observed too few software-rendered frames: the CRT
cooldown values exactly matched one and three clamped simulation steps. The test ejected
before seating, so it never attempted the CDN. Functional CI now keeps the real pipeline
and CSS viewports at DPR 0.25, waits for actual seating/contact/geometry states, and
requires a bounded quiet period followed by a separate zero-submission idle measurement.
This does not change production rendering or certify software-renderer performance.
Local SwiftShader verification now passes 43/43. It also waits for each tap's release
before replacing input instrumentation and for the sheet's CSS transition before
measuring hit targets; otherwise slow frames leak work into the following assertion.
The same revised harness passes 43/43 online on the native GPU. A separate P3 review
of this CI repair against the already committed audit found no actionable issue.
