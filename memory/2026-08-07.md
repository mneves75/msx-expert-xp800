# 2026-08-07

## v0.2.0-beta1 — desktop/mobile performance and staging

- Capped active presentation near 60 Hz and the physical drawing buffer at 2560×1440;
  the CRT now uses a 60 Hz dirty scheduler with a dynamic target up to 1536×1152.
- Removed the global transmission prepass caused by two tiny LED lenses and scheduled
  desk reflections by elapsed presentation time. Scene draw calls now meet the <150
  target: 137 at 1080p and 71 at 390×844.
- Added an SMAA runtime probe with a local FXAA fallback. Chromium retains SMAA; Safari
  on iOS 26.5 and 27 renders the full scene through the fallback.
- Mobile/coarse-pointer and reduced-motion users start without idle auto-rotation. The
  mobile control sheet is opaque and no longer blurs the WebGL canvas beneath it.
- Fixed coarse power-state publication so the HUD reaches `Ligado` and exact zero. The
  interaction probe now covers that formerly missed 99.0→99.6% boundary.
- Added DPR/buffer/host-load evidence to the profiler, isolated the staging Worker, and
  added a moderate-severity dependency audit to CI. Dependency and generated-artifact
  scans were clean; the texture atlas `cacheKey` remains a known scanner false positive.
- Verification before staging: typecheck/build, 14/14 interactions, 93/93 key map, full
  visual pose inspection, Chromium SMAA, and real Safari/iOS 27 power/HUD flow.
